# Från plattformar till plattformsförmåga

Projekt för läroboken **Från plattformar till plattformsförmåga** av **Erland Lindmark**.

## Syfte

Boken hjälper chefer i stora reglerade organisationer att fatta bättre strategiska beslut när containerteknik och plattformsförmåga införs. Fokus ligger på ledning, styrning, ansvar, målkonflikter, säkerhet, robusthet och agil förmåga på organisationsnivå.

## Struktur

- `docs/` innehåller bokspecifikation, kapitelplan, canon, terminologi, status och exportmetadata.
- `chapters/` innehåller inledning och kapitel.
- `exercises/` innehåller övningar och reflektionsfrågor per kapitel.
- `assets/` innehåller omslag, bildpromptar och eventuella bilder.
- `exports/` är reserverad för genererade EPUB/PDF/DOCX/Markdown-exporter.

## Nuvarande status

Projektet är uppdaterat med inledning och kapitel 1–12. Alla planerade kapitel är nu skapade som utkast.
