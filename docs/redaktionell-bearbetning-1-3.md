# Redaktionell bearbetning 1.3

## Syfte

Denna bearbetning justerar rubriken för kapitlens förståelsefrågor så att avsnittets funktion blir tydligare för läsaren.

## Genomförda ändringar

- Rubriken **Ledningsfrågor** har bytts till **Kontrollfrågor** i kapitel 1–12.
- Avsnittet **Beslut att fatta** har behållits oförändrat som plats för praktiska ledningsbeslut.
- Kapitelstrukturen är i övrigt oförändrad.
- Exportmetadata har uppdaterats till version **1.3**.

## Motivering

Rubriken **Ledningsfrågor** kunde tolkas som frågor för ledningsgruppens dialog eller beslutsarbete. Eftersom avsnittet främst ska hjälpa läsaren kontrollera att kapitlets huvudpoänger har förståtts är **Kontrollfrågor** mer träffsäkert.
