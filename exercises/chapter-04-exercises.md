# Övningar till kapitel 4: Från miljöbeställningar till plattformsprodukter

## Syfte

Övningarna hjälper dig att omsätta kapitlets resonemang i konkreta ledningsfrågor. Målet är att identifiera vilka återkommande behov som bör bli interna plattformsprodukter och vilka som fortfarande kräver styrd beställning eller särskild prövning.

## Övning 1: Kartlägg återkommande beställningar

Välj fem återkommande miljö- eller plattformsbeställningar.

Fyll i:

| Beställning | Frekvens | Involverade funktioner | Standardiserbar del | Del som kräver bedömning | Rekommenderad hantering |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

Använd följande rekommenderade hanteringar:

- Full självservice
- Självservice med godkännande
- Styrd beställning
- Särskild prövning

## Övning 2: Produktifiera ett behov

Välj en beställning som ofta återkommer och formulera den som en intern plattformsprodukt.

Besvara:

1. Vilket problem löser produkten?
2. Vem är målgruppen?
3. Vad ingår i produkten?
4. Vad ingår inte?
5. Vilka säkerhetskrav är inbyggda?
6. Vilka drift- och kvalitetskrav är inbyggda?
7. Vad får team göra själva?
8. När krävs godkännande?
9. Vem äger produkten?
10. Hur samlas feedback in?

## Reflektionsfrågor

1. Vilka delar av dagens beställningsflöde skyddar organisationen på ett värdefullt sätt?
2. Vilka delar skapar främst väntan, tolkning och omtag?
3. Var finns störst risk att självservice skulle skapa oönskad variation?
4. Var finns störst möjlighet att självservice skulle öka både hastighet och kvalitet?
5. Vilka återkommande undantag borde behandlas som produktfeedback?
