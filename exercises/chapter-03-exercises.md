# Övningar till kapitel 3: Containerplattformen som strategiskt vägval

## Övning 1: Formulera plattformens strategiska syfte

Skriv först organisationens nuvarande tekniska formulering av plattformsinitiativet:

> Vi inför en containerplattform för att ...

Skriv sedan om formuleringen så att den beskriver organisatorisk förmåga. Använd gärna orden:

- förändringskapacitet
- styrbar snabbhet
- standardisering
- inbyggda kontroller
- ansvar
- självservice
- robusthet

Avsluta med att jämföra formuleringarna:

- Vilken formulering hjälper ledningen att prioritera?
- Vilken formulering gör ansvarsförändringen tydligast?
- Vilken formulering visar bäst varför säkerhet och drift behöver vara med från början?
